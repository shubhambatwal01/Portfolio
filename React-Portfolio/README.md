# 💼 React Portfolio – Personal Developer Portfolio

## 📌 Overview

**React Portfolio** is a modern and responsive personal portfolio website built using **React.js, JavaScript, Tailwind CSS, and Vite**.

The website is designed to showcase my **technical skills, projects, experience, education, certifications, and professional profile** in a clean and interactive format.

It provides recruiters and visitors with an easy way to explore my development work while demonstrating my frontend development skills, responsive design knowledge, and React component architecture.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/shubhambatwal01/Portfolio.git
cd Portfolio/React-Portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will normally run at:

```text
http://localhost:5173
```

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
