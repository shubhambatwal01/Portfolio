# 💻 Shubham Batwal — Developer Portfolio

A modern, responsive, and visually polished personal portfolio built to showcase my **projects, technical skills, experience, and developer journey**.

The portfolio is developed using **React.js, JavaScript, and Tailwind CSS**, with a strong focus on responsive design, clean UI, smooth user experience, and cross-browser compatibility.

## 🔗 Repository

**GitHub:** [shubhambatwal01/Portfolio](https://github.com/shubhambatwal01/Portfolio)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shubhambatwal01/Portfolio.git
```

### 2. Navigate to the project

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
