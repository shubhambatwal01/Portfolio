# 💼 Shubham's Portfolio

_Crafted with React and Tailwind CSS, this portfolio highlights my skills, projects, and continuous growth in modern web development through an elegant and interactive experience._

## 🚀 Features

- Responsive Design for Desktop, Tablet, and Mobile
- Dark Mode / Light Mode Toggle
- Interactive Hero Section
- About Me Overview
- Skills Showcase
- Featured Projects Section
- Contact Form with EmailJS Integration
- Social Media Links
- Smooth Navigation Between Sections
- Modern UI with Tailwind CSS

## ⚙️ Installation

### Clone the Repository

```
git clone https://github.com/shubhambatwal01/Portfolio.git
cd Portfolio
```

### Install Dependencies

```
npm install
```

### Start Development Server

```
npm run dev
```

Open:

```
http://localhost:5173
```

---

## 🔧 Environment Variables

For EmailJS functionality, create a `.env` file:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```
